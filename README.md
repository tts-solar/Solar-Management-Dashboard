# Solar Management Dashboard

แดชบอร์ดติดตามผลผลิตไฟฟ้าโซลาร์ของแต่ละ Plant — ผลผลิตเทียบแผน, Efficiency, สัดส่วนที่โซลาร์ช่วยลดค่าไฟ, จุดคุ้มทุน (BEP) และตารางข้อมูลรายวัน/รายเดือน

## มี 2 แบบ — ใช้แบบไหน

| | เว็บตัวอย่าง (Demo) | แอป Offline |
|---|---|---|
| ใช้ทำอะไร | ดูหน้าตาและความสามารถของแดชบอร์ด | ดูข้อมูลจริงของ Plant คุณเอง |
| ข้อมูล | **ข้อมูลตัวอย่างสังเคราะห์เท่านั้น** (มีแถบแจ้งด้านบนทุกหน้า) | ไฟล์ CSV ของคุณ — อยู่ในเครื่องคุณเท่านั้น |
| นำเข้า CSV | ไม่ได้ | ได้ |
| ต้องใช้อินเทอร์เน็ต | ใช่ | ไม่ — และแอปถูกล็อกไม่ให้ต่ออินเทอร์เน็ตเลย |
| เปิดที่ไหน | https://tts-solar.github.io/Solar-Management-Dashboard/ | ไฟล์ `solar-dashboard-offline.html` ในเครื่อง |

> **ห้ามนำข้อมูลจริงขึ้นเว็บหรือขึ้น repo นี้เด็ดขาด** — repo และเว็บเป็นสาธารณะ ข้อมูลจริงเป็นของเจ้าของบ้าน ใช้กับแอป Offline ในเครื่องเท่านั้น

## ใช้แอป Offline

1. **ดาวน์โหลด** — เปิดเว็บตัวอย่าง แล้วกดปุ่ม **ดาวน์โหลดแอป Offline** (หรือโหลดตรงที่ https://tts-solar.github.io/Solar-Management-Dashboard/solar-dashboard-offline.html)
   - ได้ไฟล์ `solar-dashboard-offline.html` เป็นไฟล์เปล่า ไม่มีข้อมูลใดๆ อยู่ข้างใน
2. **เปิด** — ดับเบิลคลิกไฟล์ จะเปิดในเบราว์เซอร์ ขึ้นหน้า "เริ่มใช้งาน Solar Dashboard (Offline)"
3. **นำเข้า CSV** — กดปุ่ม **นำเข้า CSV** ด้านบน หรือลากไฟล์มาวางบนหน้า เลือกหลายไฟล์พร้อมกันได้ (1 ไฟล์ = 1 Plant)
   - ชื่อ Plant มาจากชื่อไฟล์ส่วนหน้าเครื่องหมาย `_` เช่น `AB_ข้อมูล 6 เดือน.csv` → Plant `AB`
   - นำเข้าไฟล์ของ Plant เดิมซ้ำ = แทนที่ข้อมูลเดิม
4. **ตั้งค่า** — กดปุ่ม **ตั้งค่า** เพื่อใส่ข้อมูล Plant (ชื่อ, วันเริ่มใช้งาน, ขนาดติดตั้ง kWp, ค่าไฟ, เงินลงทุน ฯลฯ)
   - ช่องที่เว้นว่างจะใช้ค่าเริ่มต้นหรือค่าที่คำนวณอัตโนมัติ (ตัวเลขสีเทาในช่อง)
5. **ดูข้อมูล** — คลิกชื่อ Plant หรือแถวในตาราง เพื่อเจาะดูรายปี → รายเดือน
6. **บันทึกไฟล์** — กดปุ่ม **บันทึกไฟล์** จะได้ไฟล์ HTML ใหม่ (`solar-dashboard-ปี-เดือน-วัน.html`) ที่มีข้อมูลและค่าที่ตั้งไว้อยู่ข้างใน
   - เปิดไฟล์นั้นครั้งหน้า จะเห็นข้อมูลเดิมทันที ไม่ต้องนำเข้าใหม่
   - ถ้าปิดแอปโดยไม่กดบันทึก ข้อมูลที่นำเข้าจะหายไป

### ไฟล์ที่บันทึกแล้วมีข้อมูลจริงอยู่ข้างใน

- เก็บไว้ในเครื่อง หรือส่งให้เฉพาะคนที่ควรเห็นข้อมูลนั้นเท่านั้น
- ห้ามอัปโหลดขึ้นเว็บ, ห้ามใส่ใน repo นี้, ห้ามแชร์ในที่สาธารณะ

## รูปแบบไฟล์ CSV

ไฟล์ export จากระบบ monitor ช่วงละ 15 นาที (ช่วงเวลาอื่นก็ได้) หัวตารางต้องมีคอลัมน์ดังนี้:

```csv
Date/Time,Energy Produced (Wh),Energy Consumed (Wh),Exported to Grid (Wh),Imported from Grid (Wh)
12/01/2025 00:00,-6,2215,0,2215
12/01/2025 00:15,-6,2280,0,2280
```

- วันที่เป็น `เดือน/วัน/ปี ชั่วโมง:นาที`
- หน่วยเป็น Wh — แอปรวมเป็น kWh รายวันให้เอง
- รองรับไฟล์ UTF-8 และ Windows-874 (Excel ภาษาไทยรุ่นเก่า)
- แถวที่อ่านไม่ได้จะถูกข้าม และแจ้งจำนวนให้ทราบ

## ความเป็นส่วนตัว

| ป้องกันอะไร | ทำอย่างไร |
|---|---|
| ข้อมูลจริงหลุดออกจากเครื่อง | แอป Offline ถูกล็อกไม่ให้ต่ออินเทอร์เน็ต (Content-Security-Policy) ทำงานในเบราว์เซอร์ล้วนๆ |
| ข้อมูลจริงขึ้นเว็บตัวอย่าง | เว็บตัวอย่างใส่ได้เฉพาะ `data/sample-*.csv` (ข้อมูลสังเคราะห์) และไม่มีปุ่มนำเข้า |
| ข้อมูลจริงขึ้น repo | `.gitignore` กันโฟลเดอร์ `data/` (ยกเว้นไฟล์ตัวอย่าง), ไฟล์ Excel และไฟล์ที่บันทึกจากแอป |
| พลาดทั้งหมดข้างบน | `npm run build` จบด้วยตัวตรวจ `tools/privacy-check.mjs` — ถ้าพบข้อมูลที่ไม่ใช่ตัวอย่างใน git หรือในไฟล์ที่จะเผยแพร่ build จะล้มและไม่มีอะไรถูกเผยแพร่ |

ก่อน commit ตรวจทุกครั้ง: `git status` ต้องไม่มีไฟล์ข้อมูลจริง

## สำหรับนักพัฒนา

ต้องใช้ Node.js 22

```bash
npm ci               # ติดตั้ง
npm run dev          # เปิดเครื่องมือพัฒนา แบบเว็บตัวอย่าง
npm run dev:offline  # เปิดเครื่องมือพัฒนา แบบแอป Offline
npm test             # รันเทสต์
npm run build        # สร้าง 2 ไฟล์ใน dist/ แล้วตรวจความเป็นส่วนตัว
```

`npm run build` ได้ไฟล์เดียวจบ (รวม JS/CSS/ฟอนต์) 2 ไฟล์:

- `dist/index.html` — เว็บตัวอย่าง (มีข้อมูลสังเคราะห์)
- `dist/solar-dashboard-offline.html` — แอป Offline เปล่า (ไม่มีข้อมูล)

Stack: Vite + TypeScript + Chart.js (vite-plugin-singlefile)

### Deploy

push ขึ้น branch `main` แล้ว GitHub Actions (`.github/workflows/deploy.yml`) จะรันเทสต์ build ตรวจความเป็นส่วนตัว แล้วเผยแพร่ทั้ง 2 ไฟล์ขึ้น GitHub Pages ให้อัตโนมัติ — ถ้าขั้นใดล้ม จะไม่มีอะไรถูกเผยแพร่

ตั้งค่าครั้งแรก: GitHub repo → **Settings → Pages → Source: GitHub Actions**
