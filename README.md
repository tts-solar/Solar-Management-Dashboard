# Solar Management Dashboard

แดชบอร์ดติดตามผลผลิตไฟฟ้าโซลาร์ของแต่ละ Plant — ผลผลิตเทียบแผน, Efficiency, สัดส่วนที่โซลาร์ช่วยลดค่าไฟ, จุดคุ้มทุน (BEP) และตารางข้อมูลรายวัน/รายเดือน

- เว็บ: https://tts-solar.github.io/Solar-Management-Dashboard/
- ไม่ต้อง login · ทุกอย่างคำนวณในเบราว์เซอร์ของคุณ **ไฟล์ CSV ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ใดๆ**

## ใช้งาน

1. เปิดเว็บ — ครั้งแรกจะเห็น **ข้อมูลตัวอย่างสังเคราะห์** (ไม่ใช่ข้อมูลจริง)
2. ลากไฟล์ CSV ของ Plant มาวางบนหน้าเว็บ หรือกดปุ่ม **นำเข้า CSV** — เลือกหลายไฟล์พร้อมกันได้ (1 ไฟล์ = 1 Plant)
   - ชื่อ Plant มาจากชื่อไฟล์ส่วนหน้าเครื่องหมาย `_` เช่น `MH_15 นาที ราย 6 เดือน.csv` → Plant `MH`
   - นำเข้าไฟล์ของ Plant เดิมซ้ำ = แทนที่ข้อมูลเดิม
3. กด **ตั้งค่า** เพื่อใส่ข้อมูล Plant (ชื่อ, วันเริ่มใช้งาน, ขนาดติดตั้ง kWp, ค่าไฟ, เงินลงทุน ฯลฯ)
   - ช่องที่เว้นว่างจะใช้ค่าเริ่มต้นหรือค่าที่คำนวณอัตโนมัติ (ตัวเลขสีเทาในช่อง)
   - การตั้งค่าบันทึกไว้ในเบราว์เซอร์เครื่องนั้น
4. คลิกชื่อ Plant / แถวในตาราง เพื่อเจาะดูรายปี → รายเดือน

## รูปแบบไฟล์ CSV

ไฟล์ export จากระบบ monitor ช่วงละ 15 นาที (ช่วงเวลาอื่นก็ได้) หัวตารางต้องมีคอลัมน์ดังนี้:

```csv
Date/Time,Energy Produced (Wh),Energy Consumed (Wh),Exported to Grid (Wh),Imported from Grid (Wh)
12/01/2025 00:00,-6,2215,0,2215
12/01/2025 00:15,-6,2280,0,2280
```

- วันที่เป็น `เดือน/วัน/ปี ชั่วโมง:นาที`
- หน่วยเป็น Wh — แอปรวมเป็น kWh รายวันให้เอง
- รองรับไฟล์ UTF-8 และ Windows-874 (Excel ภาษาไทยรุ่นเก่า)
- แถวที่อ่านไม่ได้จะถูกข้าม และแจ้งจำนวนให้ทราบ

## ดาวน์โหลดไว้ใช้แบบออฟไลน์

กดปุ่ม **ดาวน์โหลด HTML** จะได้ไฟล์ `solar-dashboard-YYYY-MM-DD.html` ไฟล์เดียว ที่ฝังข้อมูล Plant และการตั้งค่า ณ ตอนนั้นไว้ในตัว

- ดับเบิลคลิกเปิดได้เลย ไม่ต้องใช้อินเทอร์เน็ต ใช้งานได้เหมือนบนเว็บ (ลากไฟล์ CSV เพิ่ม, แก้ตั้งค่า, ดาวน์โหลดต่อได้)
- ส่งไฟล์นี้ให้คนอื่นได้ — **แต่ในไฟล์มีข้อมูลจริงของ Plant อยู่ ส่งเฉพาะคนที่ควรเห็นเท่านั้น**
- การแก้ตั้งค่าในไฟล์ที่ดาวน์โหลด จะบันทึกแยกของไฟล์นั้น ไม่ปนกับเว็บ

## ความเป็นส่วนตัว

repo นี้เป็น **Public** — ข้อมูลจริงของลูกค้าห้ามอยู่ใน git

- โฟลเดอร์ `data/` ถูก `.gitignore` ไว้ทั้งหมด ยกเว้น `data/sample*.csv` (ข้อมูลสังเคราะห์)
- ก่อน commit ตรวจทุกครั้ง: `git status` ต้องไม่มีไฟล์ข้อมูลจริง

## สำหรับนักพัฒนา

ต้องใช้ Node.js 22

```bash
npm ci          # ติดตั้ง
npm run dev     # เปิดเครื่องมือพัฒนา
npm test        # รันเทสต์
npm run build   # สร้าง dist/index.html (ไฟล์เดียว รวม JS/CSS/ฟอนต์)
```

Stack: Vite + TypeScript + Chart.js (vite-plugin-singlefile)

### Deploy

push ขึ้น branch `main` แล้ว GitHub Actions (`.github/workflows/deploy.yml`) จะ build และเผยแพร่ขึ้น GitHub Pages ให้อัตโนมัติ

ตั้งค่าครั้งแรก: GitHub repo → **Settings → Pages → Source: GitHub Actions**
